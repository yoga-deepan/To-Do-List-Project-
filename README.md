# 📝 TaskFlow - Modern To-Do List Application

A clean, modern, and fully-featured task management web application built with vanilla JavaScript, HTML, and CSS. No frameworks, no dependencies - just pure frontend magic! ✨

## 🌟 Features

### Core Functionality
- ✅ **Add, Edit, Delete Tasks** - Full CRUD operations
- 📊 **Priority Levels** - High (Red), Medium (Yellow), Low (Green)
- 📅 **Due Dates** - Track deadlines for each task
- ✓ **Mark Complete/Pending** - Toggle task status with one click
- 💾 **LocalStorage Persistence** - Your tasks are saved automatically

### Advanced Features
- 🔍 **Real-time Search** - Find tasks instantly as you type
- 🎯 **Smart Filters** - Filter by status (completed/pending) and priority
- 📈 **Dashboard Statistics** - Track total, completed, and pending tasks
- 🌙 **Dark Mode** - Easy on the eyes with theme toggle
- 🎨 **Responsive Design** - Works perfectly on mobile, tablet, and desktop
- 🔔 **Toast Notifications** - Get instant feedback on actions
- ⚠️ **Confirmation Dialogs** - Prevent accidental deletions
- 🧹 **Clear All** - Remove all tasks at once

## 📦 Installation

1. Clone the repository:
```bash
git clone https://github.com/yourusername/taskflow.git
```

2. Navigate to the project folder:
```bash
cd taskflow
```

3. Open `index.html` in your browser:
```bash
# On Windows
start index.html

# On Mac
open index.html

# On Linux
xdg-open index.html
```

That's it! No build process, no dependencies, no npm install. 🎉

## 💡 Usage

1. **Add a Task**: Fill in the form at the top with title, description, priority, and due date
2. **Search**: Use the search bar to find specific tasks
3. **Filter**: Use dropdown filters to view tasks by status or priority
4. **Edit**: Click the edit button on any task to modify it
5. **Complete**: Mark tasks as done with the complete button
6. **Delete**: Remove individual tasks or clear all at once
7. **Dark Mode**: Toggle between light and dark themes
